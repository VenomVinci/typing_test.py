# AI Typing Test

AI Typing Test is a simple typing speed test I made using Python. It gives you sentences related to AI, machine learning, deep learning, and LLMs, and you have to type them as quickly and accurately as possible.

While typing, the program shows which characters are correct and which ones are incorrect. At the end, it shows your typing speed (WPM) and accuracy. I made this project to practice Python and build something practical instead of only learning theory.

## What I used
1. Python
2. Curses
3. Time and random modules
